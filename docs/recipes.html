A new NPC who talks

  1. The character: src/content/characters/mira/index.ts 
    import { defineCharacter } from '@/core/define'
import sprite from './sprites/mira.gen'          // characters/mira/sprites/mira.aseprite (idle/walk tags)

export default defineCharacter({ name: 'Mira', color: '#ce93d8', blip: 'sfx/blip', sprite })
    No portraits yet? Leave them out: scenes show a coloured placeholder. (Characters, sprites)
  2. The scene: src/content/events/mira/hello/index.vn 
    show mira
mira: Oh, a visitor!
choice:
  * Who are you?
    mira: Just a traveller.
  * Bye.
set met_mira = true
    Add met_mira: false to flags.ts. (.vn scripts)
  3. On the map: in Tiled, add a 16×16 object named mira on the object layer. In the map's index.ts: 
    objects: {
  mira: { character: 'mira', facing: 'down', onInteract: ({ game }) => game.events.start('mira/hello') },
}
  4. Translate: pnpm lang --write, fill in the Polish lines. (Translations)

A quest

  1. src/content/quests/lost_cat/index.ts: 
    export default defineQuest({
  title: 'The lost cat',
  description: 'Mira lost her cat somewhere in the forest.',
  steps: { search: 'Look for the cat in the forest', return: 'Bring the cat back to Mira' },
  onComplete: ({ game }) => game.money.add(20, { notify: true }),
})
  2. Start it in Mira's scene: quest start lost_cat.
  3. A trigger in the forest (Tiled object named cat, behaviour in the forest map): 
    cat: {
  onInteract: async ({ game }) => {
    if (game.quests.step('lost_cat') !== 'search') return
    await game.events.start('forest/found_cat')
    game.quests.setStep('lost_cat', 'return')
  },
},
  4. Back in Mira's scene: 
    if game.quests.step('lost_cat') === 'return':
  mira:happy: You found her!
  quest done lost_cat
    (Quests)

  • Add helping_mira: false to flags.ts; later scenes ask if flag('helping_mira'):.
  • love changes relationship points (with a toast). Limits and start value: relationship: { start: 0, min: -50, max: 100 } in the character. In TS: game.relationships.get('mira').

A cutscene that plays once when you walk in

// in a map's objects (Tiled: a rectangle named "bridge_scene")
bridge_scene: {
  onEnter: async ({ game, world }) => {
    if (game.flags.get('saw_bridge')) return
    game.flags.set('saw_bridge', true)
    await world.camera.panTo({ x: 20, y: 6 })
    await game.events.start('forest/bridge')
    await world.camera.reset()
  },
},

The world is frozen while the handler runs, so the player can't walk away mid-scene. (Cutscenes)

A skill

// src/content/skills/frost_bite/index.ts
export default defineSkill({
  name: 'Frost bite', description: 'A cold hit that may slow.',
  mp: 4,
  target: 'enemy',                 // enemy | all_enemies | ally | all_allies | self | fallen_ally
  element: 'ice',
  delay: 1.2,                      // the user's next turn comes a little later (1 = normal)
  effects: [
    { type: 'damage', power: 1.3, uses: 'magic', against: 'resistance' },
    { type: 'status', status: 'slow', chance: 0.5 },          // chained: only if the hit landed
    { type: 'delay', amount: 0.3, evenOnMiss: true },         // separate: happens either way
  ],
})
  • Give it to someone: battle: { skills: ['frost_bite'] } in a character, or actions: [{ skill: 'frost_bite' }] in an enemy.
  • Other effects: cure, revive, delay (push a turn back), custom. Damage that nothing reduces: pure: true.
  • A battle item is the same list: defineItem({ battle: { effects: [{ type: 'heal', amount: 20 }] } }). (Skills and effects)

An item that does something while you carry it

// items/lantern/index.ts
export default defineItem({
  name: 'Lantern', icon, price: 20, max: 1,
  light: { radius: 3.5, color: '#ffe0a0' },                 // glows around the player while switched on
  onObtain: ({ game, id }) => game.items.setOn(id, true),   // found, bought, given
  onLose: ({ game, id }) => game.items.setOn(id, false),    // sold, used up, taken
  keepOnUse: true,
  useLabel: ({ game, id }) => (game.items.isOn(id) ? game.t('Put out') : game.t('Light')),
  use: ({ game, id }) => { game.items.toggle(id) },         // the inventory button
})

onObtain / onLose can do anything: set a flag, move a quest on, change a stat. Use the game they are given; item files must not import it. (Items that do something while carried)

A chest that stays open

    onInteract: async ({ game, prop, memory }) => {
  if (memory.get('open')) return game.toast(game.t('The chest is empty.'))
  memory.set('open', true)                 // saved
  await prop.play('opening', { hold: true })
  game.items.add('apple', 1, { notify: true })
},

A minigame that changes the story

// in an event
const result = await game.minigames.start('rock_paper_scissors')
if (result === 'win') {
  game.achievements.unlock('first_win')
  await say('anna:surprised', 'You won?!')
} else {
  await say('anna:happy', 'Ha! Just like old times.')
}

Minigame results are recorded in mid-scene saves, so loading replays the same outcome. (Minigames)

Saving something new

  1. Add the field in save/data.ts: visitedCaves: [] as string[].
  2. Once the game is out (players have saves), add save/migrations/vN.ts, one higher than the last (the first is v2.ts), and an example old save in save.test.ts: 
    export default defineMigration(({ engine, data }) => ({ engine, data: { ...data, visitedCaves: [] } }))
  3. Use it: game.state.update((d) => { d.visitedCaves.push('cave') }). (Migrations)

Just a yes/no or a counter? A flag needs no migration.
